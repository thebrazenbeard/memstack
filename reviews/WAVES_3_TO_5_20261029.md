## Confirmed falsifiers and dispositions

> **FAIL (fixed and unit-tested in working code):** Unknown future `startOf...Clip` markers were silently ignored and could mispair an earlier first-view onset with the wrong end. `trialStart` within a pending clip was also accepted. Masa, Thirteen and Two supplied independent counterexamples. New tests require fail-closed event vocabulary/transition handling.

> **FAIL (fixed and unit-tested in working code):** Per-file trial ordinals started at zero, causing cross-participant collisions. Trial keys now include a declared BIDS-relative source reference, content hash and ordinal. **Residual:** caller-supplied path identity is not yet independently bound to a raw acquisition manifest.

> **FAIL (fixed and unit-tested in working code):** Overwide TSV rows and duplicate headers passed `csv.DictReader` without rejection. New malformed-input tests enforce strict shapes.

> **UNKNOWN / HIGH:** EEG feature-name linting can be fooled by labels renamed as `eeg__Fp1__alpha`; no tested EDF/BIDS channel-to-feature provenance or temporal filter isolation exists. An impressive future classifier accuracy could still be answer-key leakage. No neural model is qualified.

> **UNKNOWN / HIGH:** Zero-phase filtering over an entire EDF recording can propagate later responses backward into the purported pre-response window. The current crop margin has not been validated against filter support; require synthetic post-response impulse controls.

> **UNKNOWN / HIGH:** `consent_scope_ref` is not a specific authorization decision, and generated-suggestion exposure can alter subsequent recollection. Model derivatives and third-party media need separate lineage/permission controls before human data ingestion. See [governance design](../docs/GOVERNANCE_CONTRACT_V0.md).

> **UNKNOWN / SCIENTIFIC:** Even a well-generalizing EEG recognition predictor is not a recovered episodic memory. Essex measures responses **while viewing** familiar film clips, not silent autobiographical memory export.

## Data and evidence reconciliation

Wave Five independently inspected public events TSVs under the exact upstream [OpenNeuroDatasets/ds006142 commit `6af022b2...`](https://github.com/OpenNeuroDatasets/ds006142/commit/6af022b2d66e98573bf4fc8ffc7e0d2a02c66f65) (v1.0.2). Its internal model-review count was **27 participants, 4,153 first views**: 2,212 not recognized, 515 recognized, 1,426 remembered. It also observed 1,941 second views and 6,094 clip ends; the identity `4,153 + 1,941 = 6,094` is consistent. Subjects 012 and 019 contain no `recognised` trials. The v1.0.2 [change log](https://github.com/OpenNeuroDatasets/ds006142/blob/6af022b2d66e98573bf4fc8ffc7e0d2a02c66f65/CHANGES) warns that participant 010's data were reuploaded after corruption, so old EEG must not be mixed with new labels. The MediaEval 3,484-epoch derived benchmark is a distinct denominator until reconciled.

For **locally executable** checks, the strict parser passed 11 unit tests, then the combined parser and audit suite passed 14. The actual `sub-001` TSVs produced 152 first views and 64 allowed EEG channel names. The full 27-subject audit program `scripts/audit_essex_metadata.py` is intended to independently verify complete counts and raw-byte SHA-256 values using only small public metadata; its run outcome is tracked separately and must not be invented here.

## High-value new bounded ideas

- **Four (creative):** A personal neural-memory fingerprint/temporal episode-binding graph and *forgetting-aware* external archive; evaluate retrieval gains against a no-neural lifelog and do not conflate stable fingerprints with full memories.
- **Seven/Three (science/protocol):** Binary recognized-or-remembered outcome, primary paired held-out log-loss gain over context-only, subject- and canonical-film-disjoint tests, artifact/shuffled/wrong-person controls and cohort stratification. Three-class majority `sub-001` baseline is 55.3%, not 33.3%.
- **Eight (signal):** Explicit EEG-channel picks with exact EDF/BIDS inventory match; post-response impulse test before any temporally filtered signal is admitted.
- **Six/Nine (human factors):** Freeze first unassisted recollection and capture exact elicitation/exposure receipts, a no-generation interface, revocation derivative manifest and refusal to use generated reconstructions as forensic or trauma-history truth. AI source labels alone do not prevent suggestion-induced false recollections.
